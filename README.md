# Red Hat OpenShift AI Hands-on Workshop

Participant guides for a two-day hands-on workshop on Red Hat OpenShift AI: model serving, MLOps,
GPU training, RAG, guardrails, agents and MCP. Published at https://rflorenc.github.io/openshift-ai-workshop/

Built with [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/):

```bash
pip install "mkdocs-material>=9.5,<10"
mkdocs serve -f mkdocs.gen.yml      # preview on http://127.0.0.1:8000
mkdocs build -f mkdocs.gen.yml      # static site in site/
```

`docs/` and `mkdocs.gen.yml` are generated by `build.sh` from the lab guides; the start page, credits,
style and placeholder script are in `src/`. See [Credits](docs/credits.md) for the material this builds on.
