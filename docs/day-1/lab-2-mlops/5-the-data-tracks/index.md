# Exercise 3 - The Data Tracks
>  A data pipeline moves raw data into storage we control, ready for training.

## 👨‍🍳 Exercise Intro
In this exercise, we run a small ETL (Extract, Transform, Load) pipeline that copies the song-properties dataset from GitHub into the `data` S3 bucket.

## 🔮 Learning Outcomes
- [ ] Run a data pipeline with Kubeflow Pipelines
- [ ] Find the run and its output in OpenShift AI

## 🔨 Tools used in this exercise
* <span style="color:blue;">[Kubeflow Pipelines](https://www.kubeflow.org/docs/components/pipelines/overview/)</span> - A platform for building and deploying portable and scalable machine learning (ML) workflows using containers
